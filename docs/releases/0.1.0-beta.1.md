Experimental preview of LiminalNet. Feedback and bug reports are welcome through [Issues](https://github.com/RZU-IT/LiminalNet/issues).

## Downloads

| Package | Requirements |
| --- | --- |
| Windows x86-64 ZIP | [Npcap](https://npcap.com/) installed separately. Extract the complete archive and launch `liminalnet.exe`. |
| Linux x86-64 tar.gz | Targets Ubuntu 24.04; requires libpcap. Extract and run `./liminalnet`, or use the optional `install.sh`. |
| Ubuntu 24.04 amd64 deb | Install through the package manager; requires `libpcap0.8t64` and glibc 2.39 or newer. |

Read `START-HERE.txt` in the archive. Suitable capture permissions are required. No Rust installation is needed to run these packages. Compare downloads with `SHA256SUMS.txt`.

## Included

Live traffic monitoring, connection inspection, host/service/program views, filters, favorites, PCAP/PCAPNG import, PCAP recording, alerts and configurable terminal colors. French and English interface.

## Validation and limits

The extracted Windows and Linux packages passed capture/import regression checks. Real loopback capture and recording/replay were tested on Windows and WSL2. See the [validation report](https://github.com/RZU-IT/LiminalNet/blob/v0.1.0-beta.1/docs/validation.md) for evidence and remaining work.

This beta is experimental. Windows executables are unsigned. Windows firewall changes with administrator privileges and application blocking on native Linux still need validation. WSL2 does not establish full native Linux compatibility. Process attribution and port-based service identification have known limits.
