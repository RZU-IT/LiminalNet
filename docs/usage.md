# User flow

Start LiminalNet in a terminal. On first launch, acknowledge Welcome to the Threshold. Choose an adapter or capture file, configure a BPF expression if needed, optionally select a new recording path, and start.

The dashboard shows cumulative totals and recent rates, then hosts, services and programs. Inspect lists observed flows. Notifications lists session events. Settings stores presentation preferences. Help documents only implemented controls.

Pause suspends collection. Returning to adapters asks for confirmation and ends the session. Existing capture files remain on disk. Errors explain what failed and which operation can be retried.

The current implementation status is recorded in `validation.md`; this document describes the intended complete flow, not a claim that every feature has shipped.
